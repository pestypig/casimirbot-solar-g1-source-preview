# CasimirBot solar G1 preparation source preview

This MIT-licensed source-only preview contains 19 selected first-party Python and PowerShell files under `ops/mesa/g1-preparation-v1/`, pinned to `SOURCE_SELECTION.json` from private source commit `afb8f299b502bf4fe69c8a9165bdf1ece11eba64`.

The files are no-run extractors, validators, fixture tests, and bounded-launch preparation utilities. They are not a runnable MESA package, calibrated solar baseline, admitted execution, proof, or transport result. The controlled stellar composition transport work program still has G1 open for source/input binding and baseline calibration. Source publication does not authorize an execution or advance that gate.

MESA, author data, reference inputs, environment configuration, and adjacent non-code `ops/` files are not bundled. The scripts depend on separately installed software and may reference remote intake addresses. Review their inputs, accounts, effects, and applicable upstream terms before use.
